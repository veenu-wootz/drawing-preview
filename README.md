# drawing-preview

Minimal, control-free preview of a PDF (page 1) or image, for Glide Web Embed components.

```
https://veenu-wootz.github.io/drawing-preview/?url=<encoded file url>
https://veenu-wootz.github.io/drawing-preview/?id=<google drive file id>
```

Optional params: `page=2`, `bg=white`, `type=pdf|image` (when the URL has no file extension).
